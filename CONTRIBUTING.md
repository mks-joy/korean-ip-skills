# Contributing

Contributions should improve reusable Korean IP workflows without embedding client or firm-confidential information.

## A good skill should

- define its audience and task boundary;
- state required inputs;
- identify what it will and will not do;
- distinguish source facts, assumptions, analysis, and professional judgment;
- preserve uncertainty instead of guessing;
- include explicit review gates for consequential actions;
- identify jurisdiction and freshness requirements for legal rules;
- avoid unnecessary tool, file, or network permissions;
- be testable with synthetic or public examples.

## Submission checklist

Before proposing a skill:
1. confirm no confidential or client-specific information is present;
2. run scope-control review;
3. run source/provenance review;
4. review external URLs, tools, hooks, and write paths;
5. identify any borrowed/adapted material and comply with its license;
6. include a short test scenario and expected failure behavior.

Do not copy third-party skills wholesale merely because they are public. Extract patterns deliberately, retain attribution where required, and rewrite for the Korean-IP use case.
